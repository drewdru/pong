# Pong
A Godot Pong web game with multiplayer via WebRTC.
This game was developed to be integrated with [my personal site](https://github.com/drewdru/sitedrewdru)

## Production

Export with Web template (!DISABLE EXPORT WITH DEBUG).
Add Encryption key.

Put build files to [public folder](https://github.com/drewdru/sitedrewdru/tree/main/public)
