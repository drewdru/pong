# Pong
A Godot Pong web game with P2P multiplayer.
This game was developed to be integrated with [my personal site](https://github.com/drewdru/sitedrewdru)

## Features
- Local multiplayer
- Online Peer-to-peer multiplayer via WebRTC Data Channels
- Custom SSE + REST API signaling
- Transport-independent game networking
- Web build integration with Nuxt
- JavaScript bridge for game lifecycle control


## Production

Export with Web template
> Important: Do not export with debug enabled.
> Add Encryption key.

Put build files to [public folder](https://github.com/drewdru/sitedrewdru/tree/main/public)
