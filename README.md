# Pong
A Godot Pong web game with multiplayer via WebRTC.
This game developed to integrate with [my personal site](https://github.com/drewdru/sitedrewdru)

## Production

Build the application for production with web template (!DISABLE EXPORT WITH DEBUG).
Add Encryption key.

Put build files to [public folder](https://github.com/drewdru/sitedrewdru/tree/main/public)
